
# DYPIU Student Management Portal

A responsive Student Management Portal developed as an academic project.

## Features

- Dashboard with total and active student statistics
- Add new student records
- View student records in a table
- Search students by name, roll number or course
- Delete student records
- Duplicate roll-number validation
- Local Storage for saving student data
- Student Help Assistant with predefined FAQ responses
- Responsive layout for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Structure

student-management-system/
- index.html
- style.css
- script.js
- README.md

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Use the dashboard to manage student records.

## Data Storage

Student records are stored in the browser's Local Storage. They remain available in the same browser unless the stored data is cleared.

## Disclaimer

This is an academic demonstration project inspired by a university student portal. It is not an official DYPIU system and does not connect to an institutional database.
